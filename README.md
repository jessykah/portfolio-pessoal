# Portfólio Pessoal — Jéssica Marques

## Sobre o projeto

Este projeto apresenta meu portfólio pessoal, desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas da Etec.

O site reúne informações sobre meu perfil, formação acadêmica, habilidades, conhecimentos e projetos desenvolvidos durante minha trajetória de aprendizagem.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript (Bootstrap)
- Git e GitHub

## Estrutura do projeto

- `index.html`: estrutura e conteúdo das páginas.
- `style.css`: personalização visual e animações.
- `README.md`: documentação do projeto.

## Funcionamento

O portfólio possui um menu de navegação que permite acessar as seções de Perfil, Formação, Projetos, Habilidades e Contato.

O Bootstrap foi utilizado para estruturar o layout, organizar os cartões de projetos e adaptar o site a diferentes tamanhos de tela.

O CSS personalizado complementa a aparência do site.

## Recurso novo adicionado

Foi adicionada uma animação de interação (hover) nas seções do portfólio.

Ao posicionar o cursor sobre uma seção, ela apresenta um movimento suave para cima e uma alteração na sombra, criando um efeito visual interativo.

## Como o recurso foi implementado

O recurso foi desenvolvido utilizando CSS, por meio das propriedades:

- `transition`: controla a suavidade da animação.
- `transform: translateY()`: movimenta a seção verticalmente.
- `box-shadow`: modifica a sombra durante a interação.
- `:hover`: aplica os efeitos quando o cursor está sobre o elemento.
